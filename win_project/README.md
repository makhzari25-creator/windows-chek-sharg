# چک شارژ سالن

اپلیکیشن اندروید کاملاً آفلاین برای بررسی شارژ سالن با اسکن بارکد.

## امکانات

- **انتخاب فایل اکسل** با فرمت `xlsx` (و `xls` با خطای راهنما)
- **تشخیص ستون‌ها از روی نام**: «کد محصول»، «عنوان محصول»، «تعداد» (پشتیبانی از نام‌های مترادف فارسی/انگلیسی و ی/ک عربی)
- **صفحه اصلی** با دو دکمه بزرگ:
  - شارژ سالن (فعلاً صفحه «به‌زودی»، قابل توسعه)
  - چک کردن شارژ
- **بارکدخوان دوربین** با سرعت بالا (ML Kit) و قاب اسکن
- **مقایسه بارکد با ستون «کد محصول»**:
  - اگر پیدا نباشد → پیام «این کالا در شارژ سالن نیست»
  - اگر پیدا بود → نمایش عنوان محصول و تعداد مورد نیاز
- **شمارنده اسکن** به‌صورت «اسکن شده: 3 از 6»
- **پیام سبز کامل شدن** شارژ کالا پس از رسیدن به تعداد لازم
- **ذخیره‌سازی وضعیت** تمام کالاها (با بستن برنامه اطلاعات از بین نمی‌رود)
- **ریست شمارنده‌ها** و **جایگزینی فایل اکسل** جدید
- **فونت فارسی Vazirmatn**، طراحی راست‌چین، دکمه‌های بزرگ و خوانا
- **لرزش کوتاه** هنگام هر اسکن برای فیدبک فیزیکی
- **فلش دوربین** برای اسکن در محیط تاریک

## نحوه build

### پیش‌نیازها
- Flutter 3.24.x
- JDK 17
- Android SDK 34 (Platform 34 + Build-tools 34.0.0)

### دستور build
```bash
flutter pub get
flutter build apk --release
```

فایل APK خروجی در:
```
build/app/outputs/flutter-apk/app-release.apk
```

## نصب APK

APK آماده نصب در:
```
check_hall_charge_v1.0.0.apk
```

روی اندروید:
1. فایل APK را به گوشی منتقل کنید
2. در تنظیمات اندروید «نصب از منابع ناشناس» را فعال کنید
3. روی فایل APK ضربه بزنید و نصب را تأیید کنید
4. **اولین اجرا**: اجازه دسترسی به دوربین را بدهید
5. در صفحه «چک کردن شارژ» روی «انتخاب فایل اکسل» بزنید و فایل xlsx خود را انتخاب کنید
6. بارکدخوان فعال می‌شود؛ شروع به اسکن کنید

## فرمت فایل اکسل نمونه

فایل `sample_charge_list.xlsx` به‌عنوان نمونه در همین پوشه موجود است.

| کد محصول | عنوان محصول | تعداد |
|----------|--------------|-------|
| 6291234567890 | بسته شکلات | 4 |
| 6291234567891 | بطری آب معدنی ۱.۵ لیتر | 6 |
| ... | ... | ... |

نام ستون‌ها به‌صورت هوشمند تشخیص داده می‌شوند. نام‌های پشتیبانی‌شده:

- **کد محصول**: `کد محصول`، `کد کالا`، `کد`، `barcode`، `code`، `sku`
- **عنوان محصول**: `عنوان محصول`، `عنوان`، `نام محصول`، `نام کالا`، `product`، `title`، `name`
- **تعداد**: `تعداد`، `مقدار`، `count`، `quantity`، `qty`

## نکات فنی

- **ذخیره‌سازی**: از `SharedPreferences` با encode JSON استفاده شده است. این روش برای حجم‌های متعارف (چند صد کالا) بسیار سریع و قابل اتکاست.
- **جستجوی بارکد**: یک `Map<String, Product>` به‌عنوان cache در حافظه نگه داشته می‌شود تا هر اسکن در زمان O(1) پردازش شود.
- **scan duplicate**: بارکدخوان با `DetectionSpeed.noDuplicates` تنظیم شده تا از اسکن تکراری همان بارکد در فاصله کوتاه جلوگیری کند. کاربر باید روی دکمه «ادامه اسکن» بزند تا dial بسته شود.
- **replace file**: هنگام جایگزینی فایل اکسل، شمارنده کالاهای مشترک بین فایل قدیم و جدید حفظ می‌شود.
- **JDK 17**: حتماً از JDK 17 استفاده کنید. JDK 21 به دلیل نبود `jlink` در بعضی پکیج‌ها باعث خطای build می‌شود.
